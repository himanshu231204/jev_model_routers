# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

This repository's project instructions live in `AGENTS.md`, not here — read that file first.
It covers commands (build/test/single-test), architecture and dependency direction, routing
invariants, configuration, testing rules, key contracts/modules, and common workflows
(adding an adapter, adding a provider, changing routing behavior). `AGENTS.md` is kept
up to date with `src/` and `tests/` as the implementation changes; this file exists only so
tooling that looks for `CLAUDE.md` specifically finds a pointer to it.
